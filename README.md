# box-migrate
Toolbox Migrate – Seed a new destination Toolbox container with packages, repositories,  and caches from an existing source container. Workaround for those (usually Silverblue users) who wish they could upgrade the OS within their Toolbox containers

I am not a developer or a scripting wizard. As far as I know, it is currently impossible to upgrade a fedora release within a Toolbox/Podman container. I needed an easy and automated way to keep software in a general-purpose Toolbox software up to date while not losing my packages every time I upgraded the OS. This is an AI-generated bash script that serves my use case. I'm making it public for other people who might find it useful along with any changes and improvements made as I go along.
